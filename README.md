# Русский Лес — Склад v0.7.1

Полный проект адресного складского учёта: интерфейс, серверные API, PostgreSQL/Neon, схема базы и настройки публикации на Vercel.

## Что работает

- стеллажи, полки и адресные ячейки вида `A2A`;
- наглядная схема стеллажа;
- материалы, категории, ручной и автоматически созданный артикул;
- первоначальный остаток и размещение в ячейке;
- приёмка, выдача и перемещение между ячейками;
- расчёт общего остатка и расположения материала;
- QR-коды товаров и ячеек, печать по центру листа;
- история движений и журнал изменений с выгрузкой в Excel;
- PWA-установка на Mac, Windows, iPhone, iPad, Android и ТСД.

## Технологии

- Next.js 16, React 19, TypeScript;
- серверные маршруты Next.js в `app/api`;
- PostgreSQL Neon через Drizzle ORM;
- Vercel для публикации.

## Запуск на Mac

Нужны Node.js 22+ и pnpm.

```bash
cd ~/Documents/RussianForest_Sklad_Vercel_v0.7.1
pnpm install
pnpm dlx vercel link
pnpm dlx vercel env pull .env.local
pnpm dev
```

Открыть: `http://localhost:3000`

Команда `vercel env pull` безопасно загружает в локальный `.env.local` подключение к Neon и остальные переменные проекта. Файл `.env.local` нельзя отправлять другим людям или добавлять в архив.

## Публикация после изменений

Сначала проверить сборку:

```bash
pnpm build
```

Затем опубликовать:

```bash
pnpm dlx vercel --prod
```

Постоянный адрес проекта: `https://russian-forest-sklad.vercel.app`

## Главные папки

- `app/` — страницы, интерфейс и серверные API;
- `db/` — подключение и схема PostgreSQL;
- `components/` — элементы интерфейса;
- `public/` — PWA, иконки и статические файлы;
- `drizzle/` — миграции базы.

Таблицы создаются автоматически при первом обращении к API. Существующие данные в Neon не удаляются при новой публикации.
